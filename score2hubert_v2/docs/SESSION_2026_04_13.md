### Critical interpretation lesson (added to memory)

Initial audit flagged JVS-MuSiC pairwise cos as 0.66-0.73 (vs others 0.85-0.94).
**This was misleading**: 

- Single-singer datasets (Kiritan/Itako/ONIKU/OFUTON/Natsume) have "narrow" centroids
  reflecting one specific voice. Cos between two narrow centroids of similar voices
  is naturally high.
- Multi-singer datasets (JVS-MuSiC: 100, UTAU: 8, ACE: 30+) have "blended" centroids.
  Cos between blended and narrow is mathematically lower without indicating problems.

**Audio ceiling test confirmed JVS is clean** — sounds "like different singers" because
it IS different singers (by design), not because of contamination.

GT was different: GT's audio ceiling itself sounded muddy, which was the real smoking gun.

→ **Lesson written to `memory/project_score2hubert_pipeline.md`**: never reject a dataset
on cos alone; always do audio ceiling test.

## Run 4 Plan (NEXT)

### Architecture changes (BREAKING — full retrain required)

1. **LengthRegulator + position encoding** (fix 长尾口胡)
   - Add `pos_in_note ∈ [0, 1]` per frame
   - Add `note_duration_log` per frame
   - Sinusoidal pos encoding (not linear) for position
   - These features added to frame_hidden before det_head
   - Solves: model can now distinguish "frame 30% of note" vs "70% of note"
   - Side benefit: handles JVS-MuSiC tempo variance (slow vs fast singers)

2. **F0 outlier filter** (fix 长尾跑调)
   - In F0 loss: mask frames where |dev from MIDI note| > 200c with 0.1× weight
   - Vibrato (±50-80c) preserved
   - Portamento/labeling errors filtered

3. **voicing_bce weight: 0.2 → 0.05**
   - Run 3 showed voicing val drift +6.7% in last 20K steps (clear overfit)
   - voicing has 5x train/val gap
   - Lowering weight reduces its influence on best.pt selection
