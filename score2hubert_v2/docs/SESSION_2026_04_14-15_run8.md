## K-means dropped (2026-04-15 discussion)

User's realization: "聚类之前是因为标注不一致导致的均值模糊；既然都过 SOFA 了应该不存在这问题了。接着用 det_head，效果不好再说。"

**Decision:** stay deterministic regression (continuous L1 on 768-dim HuBERT targets), no discretization.

## preprocess_sofa_realign.py design

Goal: re-align JA datasets while **preserving original segment IDs** (so Run 5 vs Run 8 per-sample A/B comparison stays possible).

Logic:
1. Parse original lab → `segment_by_pauses()` → get segment boundaries
2. Parse SOFA output lab (full song)
3. Per segment: filter SOFA intervals to `[seg_start, seg_end]` window
4. Verify voiced-phoneme count matches orig (boundary sanity)
5. Re-scale frame durations to match existing HuBERT tensor length
6. Convert SOFA phonemes (OpenJTalk-style, incl. gw/kw/0X-prefix variants) → IPA atomic segments via `OPENJTALK_TO_IPA` + extensions
7. Recompute pitch (MIDI) per new phoneme from F0 median
8. Backup old tensors to `data/processed_pre_sofa/<ds>/`, write new ones

OK rate per dataset: kiritan 94.0%, itako 86.7%, oniku 99.5%, ofuton 90.5%, natsume 96.5%. Failures mostly boundary mismatches at segment edges (voiced count off by 1) — acceptable.

## The 9-mechanism stack

After long discussion, Run 8 became a layered fix — each mechanism addresses a different observed failure mode. See `memory/project_score2hubert_run8_design.md` for the full reference. Summary:

**Data**: SOFA realign (JA), UTAU drop, pitch-shift augmentation.
**Loss**: SP=0 force, frame-consistency (within-phoneme smoothness), sustained-region 1.5× weighting, pos_aux decode of intra-phoneme + intra-note position from frame_hidden.
**Arch**: LR intra-note pos + note dur via learnable pos_scale (init 3.0) — solves Run 5's "pos_proj silent output scale 0.06" issue. DetHubertHead learnable phoneme-identity skip (init 0.5) from in_proj output to last conv block input — prevents long-sustained drift as conv blocks attenuate input signal.

## pyworld augmentation discovery

Planned: pitch shift ±2 semitones + time stretch ×0.95/1.05, 4 variants per train sample → 5x effective data.

Implementation: `scripts/preprocess_augment_ja.py` — WORLD-decomposes each segment once (cache f0/sp/ap), then re-synthesizes 4 variants. Re-extract HuBERT + F0 per variant. Duration/pitch tensors scaled accordingly.

**Quality check (kiritan, 5 samples per-phoneme centroid cos orig vs aug):**

| Aug | Mean cos | Verdict |
|---|---|---|
| aug_p+2 | 0.951-0.986 | ✅ natural distribution shift only |
| aug_p-2 | 0.941-0.983 | ✅ |
| aug_t1.05 | 0.769-0.940 | ⚠️ |
| aug_t0.95 | 0.701-0.854 | ❌ HuBERT clearly offset |

**Diagnosis:** HuBERT is very sensitive to WORLD resynthesize phase artifacts. Pitch shift preserves sp/ap almost exactly (only f0 re-scaled, phase nearly intact); time stretch requires linear interp on sp/ap across frame count → introduces phase discontinuities HuBERT notices.

**Decision:** drop time-stretch augs (delete files, filter metadata.json). Keep pitch-shift → ×3 effective aug (orig + p+2 + p-2).

Post-drop numbers:
- JA train: 2.88K orig → 2.88K orig + 5.76K aug = **8.64K unique train samples** (×3)
- ACE train: 81K
- With ja_weight=3 → JA batch share 22-24%, 237 views per variant (safely below Run 3 EN 492-view overfit line)

### Key signals

- **pos_aux 0.33 → 0.022** (15x drop in 400 steps) — **pos_head decodes pos from frame_hidden → pos signal is load-bearing**. This is the critical success criterion for the stack #3/4 design (learnable pos_scale + aux loss). Run 5 never got here.
- **consist 0.91 → 0.15** — frame-consistency loss working, within-phoneme smoothness improving.
- **hub_cos 0.98 → 0.51** — SP=0 force driving SP frames to zero accelerates cos improvement.
- **Speed 1.0-1.2 step/s stable** — per-sample Python loops in trainer's helpers + LR.forward. 30% slower than Run 5's 1.5 step/s, not the cuDNN 3-4x bug. ~21h ETA for 75K. Acceptable; optimization deferred to avoid silent-bug risk in the middle of a run.

### Nothing in the red

- No OOM, no NaN, no cuDNN slowdown
- VRAM will show at first val (step 2500)
- f0_l1 stable at 0.027 (F0 path converged fast, same as Run 5)
